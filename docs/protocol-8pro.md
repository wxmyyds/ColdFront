# 红魔散热器 8 Pro 协议

本文汇总官方 App 静态分析和第三方控制 App 的设备资料。ColdFront 当前实现的 8 Pro 功能已全部通过实机验证。官方 App 与第三方资料对温度校准的结论不一致；ColdFront 使用 `-6°C` 校准，且该温度显示已在实机上验证。以下协议只适用于 8 Pro，不能外推到 6 Pro 或 6 Pro+。

## 识别与特征

8 Pro 的广播标识为公司 ID `0x08CA`、MSD `[0x05,0x08]`，通常同时广播服务 UUID `00004a41-0000-1000-8000-00805f9b34fb`。`PPlusOTA` 表示 OTA 广播，不能据此进入散热器控制模式。

主控制服务为 `d52082ad-e805-9f97-9d4e-1c682d9c9ce6`。ColdFront 优先绑定该服务中的特征；为兼容固件变体，未找到的 UUID 仍允许从其他服务查找。

| 特征 | 用途及关键行为 |
|---|---|
| `1011` | 散热开关：写 `02` 开、`03` 关；连接时先回读，不主动写开 |
| `1012` | 风扇 raw：`40..80`，官方 9 档，可读回 |
| `1013` | 灯效与颜色；通过 GATT read 查询当前模式 |
| `1014` | 温度通知；单字节 signed 温度，部分固件使用 `[04, 温度]` |
| `1015` | 状态通知：`04` 温度、`05` 输出负载、`07` 功率限档、`08` RPM、`09` 功率 W |
| `1017` / `1018` | 超频 / 自动温控：分别写 `01` 开、`00` 关 |
| `1019` / `101A` | 部分旧固件的 RPM / 功率回读 |
| `101C` / `101D` | 新固件的 RPM（大端 16 位）/ 功率（W）通知 |
| `101F` | 温度保护配置：至少 4 字节 `[flags, eventId, high, low]`；`flags` 的 bit 2 表示过冷保护 |

## 风扇与供电限档

风扇使用单字节 raw。官方 9 档（`Jacket8ProManagerV2$a` 的 `d(I)`/`e(I)`）对应 `40, 46, 52, 58, 64, 68, 72, 76, 80`，raw→档位边界为 40–43/43–49/49–55/55–61/61–67/67–71/71–74/74–78/78+。百分比到 raw 的换算为 `40 + percent × 40 / 100`；回读值按实际档位边界归档。

`1015` 标签 `07` 的首个 payload byte 是官方限档索引，不是 raw。索引 `0..8` 对应最高 raw `40, 46, 52, 58, 64, 68, 72, 76, 80`；`8` 表示不限档。ColdFront 的档位 1–9 与官方索引 0–8 一一对应（+1），限档索引 N 最高开放第 N+1 档。处于限档时，ColdFront 会关闭超频、限制风扇上限，并在当前档过高时下发降档值；限档期间拒绝开启超频。自动温控不受这套限档规则影响。

## 模式与灯效

自动温控与超频双向互斥。开启一方会关闭并禁用另一方。散热开关 `1011` 与这两个模式没有联动。连接时官方只查询 `1011`；ColdFront 不会在连接后擅自开启散热。

`1013` 通过 GATT read 查询，`[11]` 不是查询命令。把它写入设备可能只会回读写入值，并污染灯效状态。支持的灯效 payload 为：

- `[01, 00, 00, 00]`：炫彩；`[02, 00, 00, 00]`：呼吸。
- `[03, R, G, B]`：单色呼吸；`[04, R, G, B]`：常亮。
- `[06, 00, 00, 00]`：关闭。
- 颜色值可为 RGB 三字节，部分官方路径也接受 RGB 后附 `00`；实际写入仍需按所选模式组装成完整 payload。

`05` 是场景联动模式，不作为普通灯效选项。已知模式但颜色数据不完整时，不应误判为未知模式；真正未知且非空的回包，官方界面会回退到炫彩默认值。

## 温度与保护

第三方设备资料报告温度为 signed 摄氏度，部分固件会在 `1014` 前加 `04`。官方 App 使用 `raw - 6°C` 显示，第三方资料报告无偏移；ColdFront 当前保留 `-6°C` 校准，该显示已通过 8 Pro 实机验证。

`101F` 保护配置至少包含 `[flags, eventId, high, low]`；过冷保护位为 `flags & 0x04`。ColdFront 按该位解析读回状态，写入默认阈值为 `100` 和 `-30`。其他固件的字段长度或阈值语义尚未验证。

官方 8 Pro V3 的 `OutputHasLoad` 路径没有有效数据来源；不能根据状态标签 `05` 推断设备应自动切换模式。

## 连接与排查边界

- GATT 操作必须串行。某次读写超时后，迟到回调可能仍属于旧操作；ColdFront 会等待旧回调排空，通道无法恢复时提示重连。不能仅因等待一段时间，就假设操作通道已经可以安全复用。
- 灯效未成功回读前，应用只在 read 能力可用时查询；`1011`、风扇、自动温控、超频和保护配置也以设备回读/通知确认状态，不用写入请求代替设备状态。
- `1014` 与 `1015` 的温度格式、特征属性和通知时序已在 8 Pro 实机上验证；其他固件可能不同。
