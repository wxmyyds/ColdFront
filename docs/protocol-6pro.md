# 红魔散热器 6 Pro 协议

本文依据 `/home/WXM/AllProjects/smali` 中的官方 App 静态代码整理；没有 6 Pro 实机，不能视为硬件验证结果。没有协议证据的功能不会按 8 Pro 行为推断。

## 识别与 GATT

官方扫描接受公司 ID `0x08CA`、MSD 前两字节 `[0x05,0x05]` 或 `[0x05,0x06]`，并要求广播服务 UUID `00004a41-0000-1000-8000-00805f9b34fb`。型号编码存在重叠，ColdFront 仅将名称明确包含 `6 Pro` 且不含 `Plus` 或 `+` 的设备按 6 Pro 识别。

6 Pro+ 是独立型号；本次分析的官方旧版 App 不支持它，因此本文不描述其协议。

主控制服务为 `d52082ad-e805-9f97-9d4e-1c682d9c9ce6`。官方要求 `1011`、`1012`、`1013`、`1015`；`1014`、`1016`、`1017`、`1018` 为可选特征。ColdFront 只从主服务绑定 6 Pro 特征，避免误用其他服务的同 UUID 特征；不将 8 Pro 的 `101C`、`101D`、`101F` 映射给 6 Pro。

## 命令

| 特征 | 用途 | 写入值 |
|---|---|---|
| `1011` | Hall 自动 / 开 / 关 | `01` / `02` / `03` |
| `1012` | 风扇 | 单字节 raw，官方 UI 范围 `0x28..0x50`（40–80） |
| `1013` | 灯效 | `[mode, R, G, B]` |
| `1017` | 超频（Super Mode） | 开 `01`，关 `00` |
| `1018` | 自动温控 | 开 `01`，关 `00` |

`1013` 已确认模式：`01` 炫彩、`02` 呼吸、`03+RGB` 单色呼吸、`04+RGB` 常亮、`06` 关闭。`1016` 的业务语义未确认，不据此展示或解析状态。命令按表中原始字节写入，不添加已无证据支持的校验字段。

官方界面让自动温控与超频互斥。Hall 三态命令有协议证据，但其控件在不同官方界面版本中的可见性未确认；ColdFront 暂不提供独立 Hall 设置项。超频与自动温控的设备端交互仍应以实机回归为准。

## 状态与温度

`1015` 使用 `[kind, payload...]` 格式，不使用 8 Pro 的状态标签：

| kind | 含义 |
|---|---|
| `01` | Hall，payload 首字节 `1/2/3` 表示自动/开/关 |
| `02` | 风扇 raw |
| `03` | 灯效数据 |
| `04` | 温度数据 |
| `05` | OutputHasLoad：首字节 `0x80/0x81` 为 true，`0x00/0x01` 为 false；其他值未知 |

官方温度回调只读取通知首个 signed byte。ColdFront 的 6 Pro 路径不套用 8 Pro 的 `-6°C` 校准或通用多字节启发式；单位和传感器含义仍未确认。解析时超出 `-40..80` 的值会被忽略。
